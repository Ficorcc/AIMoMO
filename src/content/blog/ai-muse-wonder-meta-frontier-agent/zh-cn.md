Meta 终于回来了。

过去一年多，AI 的聚光灯基本打在 OpenAI 和 Anthropic 身上。Meta 虽然在开源模型上一直有存在感，但在"前沿能力"这个词面前，它更像一个陪跑者。直到今天——Muse Wonder 和 Muse Wonder Full 发布，Meta 自己说这是"迄今最强模型"，而且这一次，它把宝押在了一个不太一样的地方：**给 AI 智能体做大脑。**

先看它到底是什么。Muse Wonder 系列是 Meta 十四个月前重组 AI 研究之后拿出的第一批重大成果。它俩不是普通的聊天模型，而是专门为"智能体"设计的：能同时调用多个工具、拆解多个步骤、持续工作数小时甚至数天。百万 token 上下文，多模态，法律、金融、保险这些专业领域都有专门的优化，编码则是两个模型的主攻方向。

有意思的其实是两个新概念：Active Memory（动态记忆）和 Active Focus（动态关注）。

动态记忆解决的是智能体最实际的痛点：干一个跨好几天的活，项目中途一直在变——有人提了新需求、几个测试挂了、文件改了又改，Agent 要是记不住前面发生了什么，轻则重复劳动，重则把已经修好的东西再搞坏。Active Memory 让模型能把对话之外的重要信息也长期保留下来。

动态关注则更像一个"自我纠错开关"：工具调用失败了、反复撞同一个错误，模型能判断出当前方法不奏效，主动换一条路，或者停下来问你，而不是硬着头皮瞎猜。

说实话，这两个词单独看都挺朴素——记忆和专注，这是人类做事最基本的两个能力。但放到 AI 竞争里，它们的出现标志着一件事：**这轮竞赛的焦点，已经从"谁更聪明"切换到了"谁更能干活"。**

数据也能佐证这个判断。Terminal-Bench 上 Muse Wonder Full 拿到 57%，比上一代 Muse Spark 1.3 的 33% 高出 24 个百分点；Coding Agents Index 68 分，跟 Claude Sonnet 5.5 站在同一档；ProofBench 94 分对 58 分；在 Harvey 法律智能体基准里，Muse Wonder Full 在 13.1% 的任务上通过，同场竞技的 GPT-6 Astra 是 8.6%。这些榜单的共性很明显：比的不是"回答得好不好"，而是"在真实任务里能不能跑完"。

我尤其注意它在编码上的发力。代码是最适合智能体"长跑"的场景：上下文长、步骤多、可验证。Meta 把 Muse Wonder Full 只开放给 Muse Code 订阅用户，策略也很直白——先在最能体现智能体价值的地方立住。

当然，光看基准不能说明一切，真正的考验还是有人真的拿它去跑那些几小时几天的活儿。但从行业格局看，这件事已经足够值得关注：OpenAI、Anthropic、Meta，三家手里都有了以"智能体"为核心的前沿模型，AI 的牌桌从双雄变成三国，竞争烈度只会更高。

我的判断是，接下来半年，衡量一个大模型的标准会明显变化。"会不会聊天"会被"能不能把一个复杂任务从头干到尾、还不把之前的工作搞砸"取代。而记忆和专注，就是这条路上最先要补齐的两块短板。Muse Wonder 的意义不在于它拿了多少分，而在于它第一次把这两个能力放到了台面上，逼着所有人都得跟进。
