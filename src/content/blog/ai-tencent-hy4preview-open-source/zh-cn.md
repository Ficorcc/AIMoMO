上周六（8月29日），腾讯悄悄做了一件大事：开源了旗下旗舰大模型 **Hy4preview**。

770B 参数，49B 激活参数，1M 上下文窗口——光看数字可能没什么感觉，但我看完整个发布信息后，觉得这事儿真的值得单独写一篇。

## 三个数字说清楚这意味着什么

**$3.13。** 这是有人用 Hy4preview 在真实生产环境里修了 17 个 bug 花的成本。不是跑分，不是 Demo，是真的有人在用。

**770B。** 这是总参数量。对比一下：GPT-4 系列大概是 1T 左右，Claude 3 Opus 官方没说参数但估计在 500B 上下。这个量级已经是妥妥的旗舰级别。

**1M。** 这是上下文窗口。100万 tokens，大概相当于一本《战争与和平》的长度。你可以往里面扔整本书、扔整个代码仓库、扔一个中型产品的所有文档，然后跟它聊。

这三个数字放在一起，意思是：**国产大模型，终于在「真实可用性」这个维度上，和国际顶尖玩家站在同一条线上了。**

## 开源不是情怀，是战略

很多人听到「开源」就觉得是情怀驱动、免费送。但如果你仔细看腾讯这次的操作，会发现完全不是那么回事。

Hy4preview 在 HuggingFace、GitHub、ModelScope 同步上线，还同时接入了腾讯云 TokenHub 和 OpenRouter。

OpenRouter 是什么？它是海外最大的模型聚合平台，汇集了几乎所有主流模型，让开发者可以用统一的 API 调用。腾讯选择在这个平台上线，等于是向全球开发者张开了双臂。

这是什么意思？

**腾讯想把自己变成全球开发者工作流里的一部分，而不只是一个中国公司关起门来玩的模型。**

再加上这次用的是「预览版」（preview）——说明团队很清楚这个模型还需要社区帮忙打磨，选择开源本身就是在借力全球开发者。

## 最让我意外的是定价策略

Hy4preview 上线后，Hy3 模型（原版）的免费期直接延长到 9 月 30 日。相当于新旗舰开源，老旗舰降价，这是一套完整的组合拳。

而根据科技日报的报道，GLM-5.3-Flash 刚发布，定价只有 GLM-5.3 的 1/10，限时折扣低至 1/20，仅仅是 Opus 4.8 的 1/40。

大模型的价格战打到 2026 年，已经不是「降价」这么简单了——而是在用**极限定价**把竞争对手的生存空间往死里挤。

## 对独立开发者意味着什么

作为一个平时写代码的人，我对这件事的感知特别直接：

**模型越来越便宜，越来越强，越来越容易用。**

770B 的模型，在 OpenRouter 上用 API 调用，修 17 个 bug 花 $3.13——这个成本已经比很多开发者的时薪还要低了。

我之前写过一篇文章讨论「开源模型和闭源模型的差距还有多大」，结论是差距在缩小。现在看来，差距不只是缩小，而是在某些维度上**已经在互相赶超**。

腾讯混元之前在很多人印象里是「比不过百度、阿里」的，但现在它拿出了一张足够有说服力的牌。

## 怎么看这波国产开源潮

回顾这几个月：

- DeepSeek V4 Pro 正式版发布，性能逼近 Fable 5，价格六十分之一
- GLM-5.3 开源，coding 能力提升 50%，还自带网络攻防能力
- Kimi K3 开源，2.8T 参数
- 现在 Hy4preview 跟上

国产开源大模型，正在从「追赶者」变成「竞争者」。这条路不短，但速度比我预期的快。

对于我们这些写代码的人来说，这是好事——**选择更多了，成本更低了，而且有些选择是我们自己可以部署、可以控制的**。

腾讯混元这次开源，我觉得是 2026 年下半年最值得关注的国产 AI 事件之一。不是因为它是中国公司，而是因为它真的拿出来了一个可以在全球舞台竞争的产品。

至于 $3.13 修 17 个 bug 这件事——我打算这周末自己试试看，看看这个数字到底有多离谱。
