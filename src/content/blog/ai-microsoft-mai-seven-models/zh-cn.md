11 月 17 日的 Ignite 2026，微软一次发了七款自研模型，名字统一在 MAI 这个前缀下。发布会的主线不是"我们最强"，而是"同等水平，钱少很多"。

这一点很有意思。过去两年微软在 AI 叙事里的角色，更像 OpenAI 最成功的经销商：模型是别人的，算力是自己的，Copilot 是贴牌。这次它把七款模型一张价目表摊开，摆明要自己站在货架上。

## 七款模型，一张价目表

按微软自己的测试口径（注意，是它自己的）：

**MAI Code 2**，编程主力。对比 GPT-6.1 Sol，拿到约 98% 的表现，花约 40% 的钱；对比 Claude Opus 5.5，约 96% 的表现、约 5% 的钱。在"照着描述搭界面"的盲测里，68% 的开发者更愿意选它而不是 GPT-6 Sol。已上线 GitHub Copilot。

**MAI Code 2 Flash**，干解释代码、小改动、修 bug 这类活。对标 GPT-6 Luna 用 65% 的钱，对标 Claude Haiku 5.5 用两成。

**MAI Cyber 2 Flash**，找漏洞。在 CyberGymE2E 上和 GPT-6 Astra 打平，成本不到对方的 2%；输出 token 的成本比上一代 Cyber 1.1 Flash 降了 86%——而上一代已经在 MDASH 系统里承担了将近四成的检查。

**MAI Image 2.7**，图像编辑榜（Artificial Analysis）第一，压过 GPT Image 2.6 Sunburst，价格约五分之一；Flash 版一千张图十美元上下。

**MAI Realtime 1**，语音对话，微软说内部与外部测试都胜过 GPT-Realtime 2.1，音频处理每分钟一美分起。

**MAI Transcribe 2**，转写。医疗侧的 Dragon Copilot 靠它，一个月处理约一千万次医患对话，多语种转写错误率砍半，约三分之一美国医生在用。

**Decision 1.1**，这个不是聊天模型，是路由器：把每个请求派给合适的模型。微软说它比 GPT-Sol 6.1 快 50 倍、便宜 79 倍，已有约 4000 家客户。

## 比分数更值得看的是「权重」

七款模型里，我真正在意的不是哪个榜单第一，是随之上线的 **MAI Licensed Weights**。

说白了：把前沿 MAI 模型交给你，你可以用自己业务数据微调，然后跑在你自己的 Azure 环境里。谁能访问、数据去哪、版本怎么管，都由你决定。

微软在公告里写了一句非常商人的话，大意是：没有人愿意把自己的 IQ 倒进别人的模型里；用开放权重的时候，你也很难说清它从哪来、拿它当底座撑你最值钱的 IP 会不会出事。

这句话摆明了在打两个市场：一边是"想要模型但要自主"的大企业，一边是"怕数据出门"的行业客户。AT&T 已经有例子，做 5G 网络运维分析的定制模型，据微软说比 GPT-6.1 Sol 强，成本低 50 倍。这类定制模型由"Frontier Company"这条线交付，最后嵌进客户自己的产品里。

硬件也在这条线上。第二代自研加速器 Maia 200 已经进了生产环境。模型、芯片、云，三件事凑齐了，才算真的把"自研"两个字站住。

## 我认为

第一，这次的重点是"重新定价"，不是"刷新天花板"。谁在榜首其实已经不那么好卖，买方的第一句话越来越像"我这个月单任务成本多少"。模型竞争的单位，正在从 token 价格换成"完成一件事的钱"。这次七款模型全是按这个单位写的文案。

第二，微软真正的护城河不是模型，是分发。GitHub Copilot、Microsoft 365、Dynamics、Azure——它有一堆天然分发口。模型稍微差一点、便宜十倍，从分发口进去就能回收市场。这也是它敢把"98% 的表现、40% 的价格"直接写进 PPT 的原因：剩下的 2% 它并不打算用模型赢，而打算用"就在你手边"赢。

第三，对做产品的人也有一层现实提醒：当模型价格按季度腰斩，你产品里"我们调了某个贵模型"这件事就不再是壁垒。能被替换的东西会不断被替换。真正沉淀下来的，还是你那套只有你有的数据、流程和分发。

至于微软和 OpenAI 的关系——对外还会说是伙伴，但从今天这七款模型开始，定价权至少有一半回到了自己手里。这大概是分销商最好的结局：自己变成了货。
